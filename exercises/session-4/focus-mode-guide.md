# Focus Mode Guide

## Available Focus Modes

| Mode | Use When | Context Loaded |
|------|----------|----------------|
| `default` | General development | Full project overview |
| `bug` | Investigating issues | Error logs, recent changes, known issues |
| `feature` | Building new features | Specs, related code, architecture docs |
| `refactor` | Code cleanup | Code quality metrics, style guides |
| `review` | Code review | Changed files, standards, security checklist |

## Tips

- Start each work session with the appropriate focus mode
- If your focus changes mid-session, re-run StartSession with the new mode
- Review the generated session plan — it's your roadmap for the session
- The AI's recommendations change significantly based on focus mode
