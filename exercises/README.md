# Training Exercises

Each session has its own folder with instructions and resources.

| Folder | Session | Focus |
|--------|---------|-------|
| `session-3/` | Environment Setup & Configuration | Setup your AI development environment |
| `session-4/` | Session Start — Context-Aware Dev | Practice /StartSession workflows |
| `session-5/` | Assisted Coding Fundamentals | Refactor, Implement, Brainstorm exercises |
| `session-6/` | Session End & Quality Gates | /EndSession, code review, security audit |
| `session-7/` | PRD Validation & Feasibility | /PRDValidate, /PRDEnrich, /PRDFeasibility |
| `session-8/` | Work Breakdown & Cycle Planning | /Breakdown, /CyclePlan |
| `session-9/` | AI-Assisted Research & PRD Creation | Numbered prompt chain (#1–#10) from vague request to validated PRD |
| `session-10/` | Security, Quality & Governance | Security vulnerability hunting |
| `session-11/` | Measuring Impact & ROI | Before/after time trials, baseline metrics, ROI worksheet |
| `session-12/` | Capstone — AI Transformation Rollout Plan | Pull Sessions 1–11 into a presentable rollout plan |
